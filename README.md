# Siphome — Smart Home Landing Page

A responsive marketing landing page for a smart home concept, built during
my HTML & CSS training at Gaza Sky Geeks.

## 📝 Context

This was an early exercise in my training, focused entirely on structuring
a multi-section responsive page with HTML and CSS — before JavaScript was
introduced later in the curriculum. As a result, some interactive elements
(the testimonials slider, the dropdown menu options, and form submission)
are present visually but not yet wired up with logic.

## ✨ Sections

- Hero section with call-to-action buttons
- Features grid (automatic threat detection, diagnostics, disaster prevention, 24/7 service)
- "Update" section (Monitor, Maintenance, Replace, Repair)
- Services list
- Testimonials slider (static layout)
- Contact form
- Footer with navigation and social links

## 🛠️ Built With

- HTML5
- CSS3 (responsive layout, custom sections, no framework)

## 🎯 What I Learned

Structuring a long, multi-section responsive marketing page with plain CSS —
laying out complex sections (feature grids, an image-heavy "update" section,
a testimonials slider) before introducing any JavaScript.

## 🚧 Possible Next Step

Revisiting this project to add the interactivity it was originally designed
for (slider navigation, populated dropdown, form validation) using the
JavaScript skills I've since developed.
